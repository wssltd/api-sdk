# Security

## Reporting a vulnerability

If you find a security problem in these SDKs or in the Wizard Application API, please email **support@wizardapplication.com** with "Security" in the subject line. Don't open a public GitHub issue.

Please include:

- which SDK and version, or which API endpoint, is affected
- what the problem is and what someone could do with it
- the steps to reproduce it

We'll confirm we've received your report within two working days and keep you updated while we investigate. Please give us reasonable time to fix the problem before you share details with anyone else.

## Supported versions

Security fixes are made to the latest release of each SDK. Update to the newest version to get them.

## Keeping your integration secure

- Keep API keys in environment variables or a secrets manager, never in source control.
- Use the SDKs in server-side code only. Never put an API key in a web page or a mobile app.
- Give each API key only the permissions it needs, and remove keys you no longer use under **Settings > API Keys**.
